# COSMII RESCUE!

スマホ横画面の救出アクション。左手で左右、右タップで上昇。PCではA/Dまたは左右キー、Space・↑・Wで上昇します。

## 現在の構成

初回は約56秒のプロローグ動画を表示し、動画を最後まで見ると実操作チュートリアルへ、右下のSKIPではタイトルへ進みます。自動チュートリアルは初回の動画を見終えたときのみ。途中で練習をやめても、以降の起動はタイトルへ進み、PLAYは直接本番を開始します。タイトルの「遊び方」からいつでも練習でき、動画の再視聴後はタイトルに戻ります。導入終了と練習完了は別々に保存します。2回目以降の起動では、AIRIS GAMESロゴのあとに14秒の短縮版（`Asset/movie/Cosmii_Rescue_Short.mp4`）を流し、画面のどこをタップしてもタイトルへ進みます。音声つき自動再生が制限された環境では消音で再生し、再生自体ができない場合はそのままタイトルへ進みます。音声つき自動再生がブラウザに制限された場合は、動画をタップしてください。

練習では左右移動 → 上昇 → 仲間の救出 → リングへの帰還を体験できます。障害物なし、練習位置への復帰あり。練習スコアは保存・ランキング送信しません。完了後は本番へ、途中終了ではタイトルへ戻れます。

通常ゲームはNORMAL/HARD。スコアはHOMEへ届けた仲間1匹＝1点（色・レア度・コンボ・まとめ届けによる倍率なし）。同行中の仲間は未得点、飛距離は結果画面の参考記録です。新スコアは `cosmii-rescued-v1` 系の保存キーで旧記録と分離します。仲間をHOMEへ届けると得点が確定・保存され、20匹を一度に届けると12秒のレインボーモードが発動します。1回のプレイ中、HOMEへ3回帰るごとにエリアが進みます（そら → ゆうやけ → ネオン → うちゅう）。背景・障害物の種類・速さはエリアで決まり、連れている仲間が多いほど障害物の間隔が短く、速く、きけん系が増えます（経過時間の影響は小さな補正のみ）。ゆうやけではレア仲間と専用の鳥、うちゅうでは専用の隕石が出て、重力が少し弱くなります。到達エリアは結果画面に表示し、モードごとに最高到達を保存します。調整値は `src/areas.js`（エリアごとの割合・速さ・重力）、`src/difficulty.js` の `pressure()`、`src/incoming.js`、`src/rainbow.js` を参照してください。鳥・隕石の原画（SVG）は `Asset/objects/source/` です。

**ぶつかったとき**：バナナ・紙（チラシ）・シャボン玉・雲・ジュースは「効果系」でダメージなし。それ以外はNORMALでも開始直後から必ずダメージ（仲間がいれば仲間が離れ、主人公に直撃なら♥も減る。仲間がいなければ♥が減る）。効果系は点線の白い輪で見分けられ、当たると左側に「シャボン玉：ゆっくりしか進めない」などの帯と残り時間を表示し、主人公にも泡・すべる線・もくもくを表示します（`src/effects.js`）。

**風**：ゆうやけ以降（HARDはそらから）、ときどき「向かい風」（前に進みにくい）か「追い風」（スピードアップ）が吹きます。1.6秒前に予告し、5秒吹きます。エリアが進むほど頻繁で強く、向かい風の割合が増えます（`src/wind.js`、強さと間隔は `src/areas.js` の `wind`）。

計測ビルドは1.3.2-collectionです。NORMALは色別帰還記録を備えます（開始30秒の無敵と初帰還までの同行者保護は2026-11-05に廃止）。プロフィールは黄緑のみ最初から開放し、水色5・ピンク10・赤20・紫30体の累計帰還で開放します。PLAY直下と結果画面にNORMALの累計帰還数を表示します。スコア保存キーは旧NORMALと分離し、旧オンラインランキングとは分離した救出数ランキング（cosmii-rescue-v1）に登録します。本番Supabaseの新RPCは2026-11-02にHTTP 200を確認済みです。新規環境には追加SQLの反映が必要です。手順は [RANKING-DEPLOY.md](RANKING-DEPLOY.md) を参照してください。HARDにも手動の技ボタンを適用しています。仕様・計測定義は [PSF-IMPLEMENTATION.md](PSF-IMPLEMENTATION.md) と [ANALYTICS.md](ANALYTICS.md) を参照してください。

終了時にSNS・LINEスタンプのポップアップを表示し、閉じると結果・図鑑・再挑戦へ進めます。SNSは公式リンクと提供ロゴ、LINEは提供されたスタンプ見本を表示し、リンク未設定のため準備中です。アイテムは3種類が取得可能で、追加6種類の影絵は図鑑だけの予告表示です。物語モードは撤去済み。コラボ機能は設定上OFFですが、コード・素材・テストは保持しています。

## 仲間の技

NORMAL/HARD共通で、同じ色の仲間をピンク3匹・水色4匹・赤5匹・紫6匹救出すると画面下の顔ボタンが発動可能になります。全技とも演出後5秒間持続します。ピンクはすり抜け、水色は繰り返しダメージを防御、赤は0.5秒ごとに周囲400pxの障害物を破壊、紫は1秒ごとに450px以内の近い仲間を最大3匹引き寄せます。発動中は顔ボタンに残り秒数・時間バーを表示します。一時停止や他の技の演出中は残り時間も止まります。発動時は0.6秒間シミュレーションを止めてカットインし、再開後0.8秒はダメージを防ぎます。得点・仲間数は消費せず、使った色のゲージだけ0に戻ります。1回のプレイ中は、技を使うたびにその色の必要数が1匹増えます（例：ピンク 3 → 4 → 5 → 6、増加は+3まで。次のプレイで元に戻ります）。拾い直し・紫の技での救出はゲージ対象外、満タン時の余剰は持ち越しません。通常の練習では発動できませんが、操作ガイドの技ステップではピンクの技を体験できます。従来の水色の自動防御は本番では手動ガードに置き換わります。

帰還時のライフ回復はありません。HARDは衝突前から仲間が0の場合に終了し、最後の仲間を失った衝突では続行します（強い障害物の主人公への直撃は即終了）。

## 毎日のミッション

タイトルの「ミッション」に、毎日（端末の日付で0時に切り替え）3つの小さな目標が出ます。2つはプレイ中の目標（例：ピンクを10匹助ける、8匹まとめて帰還、HOMEへ合計25匹、エリア「ゆうやけ」まで行く、技を3回使う、3回あそぶ）、1つはふれあいの部屋の目標（おやつをあげる、ふれあう）です。同じ日なら誰でも同じ3つ。NORMAL・HARDの両方で進み、練習は数えません。

達成したら「受け取る」でごほうび：1つ目と3つ目は **ほしクッキー**（部屋でだけあげられる特別なおやつ。あげると信頼度+5）、2つ目は **部屋のみんなの信頼度+5**。3つとも受け取ると **ボーナスで次の家具を1つ早く開放**（全部開放済みならクッキー×2）。未受け取りがあるとタイトルのボタンに数字、未達成があると赤い点を出します。プレイ中に達成すると「ミッション達成！」と通知します。

iOSの1日後のお知らせは「今日のミッションが届いたよ」に変更し、タップして開くとミッション画面を表示します（7日後のお知らせは従来の文言）。データは `cosmii-missions-v1`（ミッションの進み・クッキーの数・早く開放した家具・連続達成日数）。ロジックは `src/missions.js`、画面は `src/community-ui.js` の `missions()`。

## ふれあいの部屋

タイトルの「ふれあい」から、クレーンゲームのケース風の部屋へ進みます。黄緑は最初から滞在し、NORMALでHOMEへ届けた色の仲間が部屋を歩きます（各色1匹＋黄緑、表示上限5匹）。短い丸胴・腕2本・脚2本の二足歩行4コマ画像を使い、左右の移動に合わせて反転します。黄緑は歩行・ふれあいとも横線の目と無表情を保ち、体の動きだけで反応します。ほかの色は表情も変わります。個体を選び「ふれあう」でアップにすると、タップ・指の移動・キーボード操作で目や口の表情が変わります。「お部屋にもどる」で散歩へ戻れます。

同じ画面の「もようがえ」で4か所へインテリアを追加・交換・撤去できます。星のクッションは最初から、星のお花は累計5匹、おもちゃ箱は15匹、おほしさまライトは30匹のNORMAL帰還で開放します。救出数や所持アイテムは消費しません。選択した色・配置は `cosmii-friend-room-v2` に保存し、旧v1から選択色を引き継ぎます。保存が使えない環境でも遊べます。

画像は `Asset/room`、生成プロンプト・透明化QCの記録は `output/` に保存。容量整理により中間PNG・GIFは削除済みです。背景とインテリア・キャラは別レイヤーで、歩行範囲と家具の衝突領域は `src/room-data.js` に定義しています。`npm run build` は現行の部屋・信頼度画像を配布対象に含めます。検証は `node scripts/verify-friend-room.mjs`。

## 起動・配布

Node.js 20以降で `npm start`。PCでは http://localhost:5180 を開きます。スマホはPCと同じWi-Fiに接続し、PCのLANアドレスとポート5180を使用してください。接続が遮断される場合は `Enable-Mobile.cmd` を実行します。許可範囲はプライベートネットワーク内のTCP 5180です。

`npm run build` でdistへ静的配信データを出力。iOSへ反映する場合は続けて `npx cap sync ios` を実行します。Windowsでの同期は、iPhone実機での動作確認やXcodeビルドの代わりにはなりません。

プロローグの原本は `Asset/movie/Cosmii_Rescue_Opening.mp4`。素材は `Asset` で編集し、再生成される `dist` に直接追加しないでください。ゲーム本体は `src/engine.js`、練習は `src/training-game.js`、描画は `src/renderer.js` です。

## 検証・保守

`npm test` で物理・救出・帰還・保存・練習などを検証します（173件）。ブラウザ検証は scripts内の `verify-*.mjs`（ローカルサーバー起動後に実行）。主要なものは `verify-opening-flow.mjs`、`verify-guided-practice.mjs`、`verify-result-social.mjs`、`verify-total-returned.mjs`、`verify-joystick.mjs`。2026-11-04に現行仕様と合わない旧検証17本を削除しました（`REVIEW.md` 参照）。`verify-collaboration*.mjs` はコラボON時用、`verify-title-rotation.mjs` はFirefox/WebKitが必要です。

通常ゲームだけを検証する場合は `?opening=off&analytics=off` を付けます。素材監査は `node scripts/audit-unused-assets.mjs`。これは削除を行わず、動画・音源の制作入力も考慮した一覧を `test-results/unused-assets.json` に出力します。LAN用サーバーは公開ゲームファイルだけを配信し、`.git`・ローカルデータ・ログは配信しません。

今回の整理記録は `REVIEW.md`、削除ファイルの一覧・ハッシュは `cleanup-review.json`。過去の実装経緯は `PHASE1-IMPLEMENTATION.md` に保持しています。

### ふれあいのタップと信頼度

アップ画面はコスミーと左下の戻るボタンのみを表示します。タップ・なでた位置に、その色のコスミーのネオンシルエットを表示し、喜び・困惑・軽く怒る反応を切り替えます。黄緑は横線の目と無表情を維持し、姿勢で反応します。連続タップでは軽く怒ることがあります。

信頼度は色ごとに0〜100で保存します。反応したタップ1回につき1（0.35秒の間隔制限、1回の訪問で最大10）を、部屋へ戻るときに加算します。触らずに戻っても加算されません。救出数や家具の解放条件には影響しません。既存の部屋データはそのまま読み込み、信頼度だけ0から追加します。

追加画像の生成プロンプトとQC記録は `output/room-moods/`、タップ位置・反応・信頼度のブラウザ確認は `node scripts/verify-room-touch.mjs` です。

### フォント

画面全体とCanvas描画は Mochiy Pop One に統一しています。Google Fonts公式配布の全字形版からWOFF2へ圧縮し、`Asset/fonts/MochiyPopOne-Regular.woff2` をローカル配信します。外部フォント通信は不要です。出典：https://github.com/google/fonts/tree/main/ofl/mochiypopone 。SIL Open Font Licenseは同ディレクトリの `MochiyPopOne-OFL.txt` に同梱しています。

### 指さし操作ガイド

ホームの「遊び方」と初回導入は、実際のゲーム画面で操作します。左スティックで左右移動 → 右タップで上昇 → ピンク3匹を集めてわっかへ帰還 → 顔ボタンで5秒のすり抜けを発動 → 「20匹を一緒に届けると…？」の予告、の順です。ガイドは操作対象と画面内の仲間・わっかを追従して指さします。障害物のない練習用状態で、保存済みスコア・累計帰還・技の進行には影響しません。

確認：`node scripts/verify-guided-practice.mjs`（実スティック・タップ・帰還・技発動、縦横表示）。
